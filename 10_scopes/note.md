# 🔹 Scope in Python

- Scope refers to the region of a program where a variable is recognized. Python uses the LEGB rule to determine the scope of a variable:

L – Local (inside the current function)

E – Enclosing (in enclosing functions, if there’s a nested function)

G – Global (defined at the top level of a script/module)

B – Built-in (Python’s built-in names, like len, range)


- A closure is a function object that remembers values in enclosing scopes even if the enclosing function has finished executing.
